# 在线对话记录页（第二次作业支撑材料）

本目录是提交件《第 6 组 + 金行云（第二次作业）.pdf》中所附链接对应的网页源码，
托管于 GitHub Pages。

## 线上地址

https://a3289411524-sys.github.io/esa-ai-chat/

## 内容说明

- 完整保留 2026-10-14 至 2026-10-29 期间，用户提问与 AI 回应的全部文字往来
  （92 轮 / 94 次提问 / 629 条 AI 文字回应），按九个阶段分节编排
- 每轮标注该轮 AI 实际发起的工具调用次数与工具名（共 954 次），用于说明
  AI 参与设计的深度与过程可追溯性
- 不展示工具的原始输出（网页正文、文件内容等），以控制篇幅并避免无关信息干扰评审

## 脱敏规则

- 全部第三方网址去链接化处理，页面零外链（不引用任何外部 CSS / JS / 字体文件）
- 指向盗版教材站、作业代做平台、搜索引擎结果页的站点名做中性化替换，
  替换处以方括号标注
- 除上述两项外，全部提问与回应的文字内容未改动、未删减、未重写

## 重新生成

数据源为本地 SQLite 导出的问答流水与快照中的工具调用统计，生成脚本见
上级目录 `_生成脚本/`（`gen_chat.py` 及配套导出脚本）。重新生成后提交本目录的
`index.html` 即可，GitHub Pages 会自动重新部署。

## 本地预览

用浏览器直接打开 `index.html` 即可，无需构建步骤。
