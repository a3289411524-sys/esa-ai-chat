# 在线对话记录页（第二次作业支撑材料）

本目录是提交件《第 6 组 + 金行云（第二次作业）.pdf》中所附链接对应的网页源码，
托管于 GitHub Pages。

## 线上地址

https://a3289411524-sys.github.io/esa-ai-chat/

## 两个页面

| 文件 | 内容 | 定位 |
|---|---|---|
| `index.html` | **提示词迭代全过程**（主线专题） | 首页。从 92 轮交互中抽出一条主线：**第一个提示词没有产出想要的结果**，此后每一轮返工都对应用户补上一条此前没写进提示词的约束。含 12 个关键修正节点、6 项补齐的约束维度、3 次返工级事件、质量机制建立的三阶段过程、8 条可复用提示词模板 |
| `full.html` | 完整对话流水 | 全部 92 轮逐条问答，按九个阶段分节编排，每轮标注该轮 AI 实际发起的工具调用次数与工具名 |

两页均由同一份中间数据生成，内容口径一致（92 轮 / 94 次提问 / 366 条 AI 文字回应 /
1017 次工具调用 / 19 种工具 / 15.4 天跨度）。

## 内容与脱敏

- 专题页的每一项引用都是**原始提示词原文**，节选处以「（略）」标出，并给出跳转
  完整流水对应轮次的链接，可逐条核对
- 不展示工具的原始输出（网页正文、文件内容等），只保留「每轮调用了什么、调了几次」，
  既证明 AI 参与深度，又不把评审淹没在噪声里
- 全部第三方网址去链接化，两页均为**零外链**（不引用任何外部 CSS / JS / 字体文件）
- 指向盗版教材站、作业代做平台、搜索引擎结果页的站点名做中性化替换，
  替换处以方括号标注
- 除上述两项外，全部提问与回应的文字内容未改动、未删减、未重写

## 重新生成

数据源为本地消息库与 session 快照，脚本全部在 `_生成脚本/`（与中间数据同级，可直接运行）：

| 顺序 | 脚本 | 作用 | 产出 |
|---|---|---|---|
| 1 | `export_qa.py` | 从本地消息库 SQLite 导出问答流水 | `qa.json` |
| 2 | `extract_toolcalls.py` | 从 session 快照统计每轮工具调用次数与工具名 | `tools_by_turn.json` |
| 3 | `gen_iteration.py` | 渲染提示词迭代专题页 | 上级目录 `index.html` |
| 4 | `gen_chat.py` | 渲染完整对话流水页 | 上级目录 `full.html` |

跑完提交本目录的 `index.html` 与 `full.html` 即可，GitHub Pages 会自动重新部署。

`config.py` 里的 `RECORD_CUTOFF_TS` 是**记录截止点**（导出会随会话继续增长，
必须固定截止点才能保证网页统计与已交付 PDF 严格一致）。`mdkit.py` 是两套渲染
共用的脱敏与 Markdown 渲染模块——改脱敏规则只改这一处。

依赖：`export_qa.py` 需 `sqlite3`，`extract_toolcalls.py` 需 `json/os/bisect`，
`gen_iteration.py` 需 `json/os/datetime`，`gen_chat.py` 需 `json/re/html/os/datetime`，
均为标准库，无第三方依赖。

## 本地预览
